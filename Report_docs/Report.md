# تقرير مشروع نظام قاعدة بيانات العيادة الذكية (Smart Clinical Database System)

## مقدمة
نظام قاعدة بيانات MySQL معيارية مصمم لإدارة عيادة خارجية خاصة. يركز النظام على كفاءة إدارة البيانات من خلال هيكلية EER متقدمة تضمن تقليل تكرار البيانات ودقة العمليات السريرية والمالية.

## هيكل قاعدة البيانات (الكيانات والجداول)
يتكون النظام من 8 جداول رئيسية مترابطة:
- **PERSON**: الكيان الأب (Supertype) الذي يحتوي على البيانات الأساسية.
- **PATIENT & DOCTOR**: كيانات فرعية (Subtypes) ترث من PERSON.
- **MEDICINE**: لإدارة مخزون الأدوية.
- **APPOINTMENT**: لربط المرضى بالأطباء وجدولة الزيارات.
- **TREATMENT**: لتسجيل تفاصيل العلاج والتكاليف.
- **PAYMENT**: لإدارة العمليات المالية.
- **TREATMENT_MEDICINE**: جدول وسيط لحل علاقة (متعدد إلى متعدد) بين العلاجات والأدوية.

## المميزات التقنية المنفذة
1. **تصميم EER**: استخدام مفهوم التعميم والتخصيص (Generalization/Specialization) لتمثيل العلاقة بين الأشخاص والمرضى والأطباء.
2. **استعلامات SQL**: تنفيذ استعلامات الربط (JOIN)، الاستعلامات المتداخلة (Nested Queries)، والدوال التجميعية (Aggregate Functions).
3. **الأتمتة**: إنشاء **View** لملخص المواعيد و **Trigger** لإدارة العمليات التلقائية.
4. **سلامة البيانات**: تطبيق قيود المفاتيح الأساسية والأجنبية وقيود التحقق لضمان دقة البيانات المدخلة.
